About

Project Title

AI Knowledge Assistant: A Knowledge-Based Learning and Reasoning System

Objective

To provide a clean, accessible, and self-paced environment for students to explore core Artificial Intelligence principles, state-space search algorithms, logical reasoning, knowledge representation, and natural language techniques.

Methodology

The system operates on a 100% client-side local Knowledge Base and a deterministic pattern-matching Rule Engine. It processes inputs locally without external API calls or large language model services.

Technologies Used

HTML5 Vanilla CSS3 JavaScript (ES6+) Fetch API JSON
