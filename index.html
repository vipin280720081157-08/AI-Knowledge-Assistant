About the Project

Academic Lab Project for AI Techniques & Algorithms (22UAD301)

📌 Project Overview

Title: AI Knowledge Assistant: A Knowledge-Based Learning and Reasoning System

Subject: Artificial Intelligence Techniques and Algorithms (Course Code: 22UAD301)

Developer: Vipin (GitHub: Vipin28)

Deployment: 100% Client-Side Static Application on GitHub Pages

🎯 Objective

To design and implement a rule-based learning assistant that provides students with a structured, interactive environment to explore foundational AI concepts, algorithms, logic systems, and natural language applications without reliance on external LLM APIs.

⚙️ Methodology

  • Knowledge Base (KB): 5 structured JSON files detailing the entire 22UAD301 syllabus.
  • Rule Engine: Deterministic pattern-matching engine with string normalization and keyword extraction.
  • Response Builder: Dynamic HTML renderer with string sanitization and automated related-topic linking.

🛠️ Technologies Used

HTML5 Vanilla CSS3 JavaScript (ES6+) Fetch API JSON GitHub Pages
